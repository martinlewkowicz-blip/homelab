# Homelab

Privates Homelab zur praktischen Arbeit mit Linux, Docker,
Netzwerkdiensten, Monitoring, Backup und IT-Sicherheit.

## Verwendete Technologien

- Linux: Debian oder Ubuntu Server
- Container: Docker und Docker Compose
- Netzwerk: Router, Firewall, VLANs, DNS
- Remote-Zugriff: WireGuard VPN
- Monitoring: Uptime Kuma oder Grafana
- Backups: Restic, BorgBackup oder rsync

## Ziele

- Linux-Server selbst betreiben und absichern
- Dienste reproduzierbar mit Docker bereitstellen
- Netzwerk und Zugriffe sinnvoll trennen
- Backups erstellen und Wiederherstellung testen
- Infrastruktur nachvollziehbar dokumentieren
